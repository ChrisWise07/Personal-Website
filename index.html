Selected Projects

Quantum Computing Regression ML arXiv:2505.03397

Quantum Feature Space of a Qubit Coupled to an Arbitrary Bath

Demonstrates that quantum noise operators can be inferred using regression more efficiently and accurately than deep learning approaches. Introduces a compact parameterisation to characterise complex qubit-bath interactions.

Honours Thesis Deep Learning Optimal Control

Machine Learning for High Fidelity Qubit Control

Honours thesis extending physical models of qubit-environment interactions to infer system noise from experimental data. Used deep learning and gradient-free optimisation to synthesise control pulses achieving over 99% process fidelity.

Code PDF
Quantum Circuits PSO Algorithm Error Mitigation

PSO to Infer Quantum Computer Circuit Errors

Calibrated quantum circuit error models against hardware data using Particle Swarm Optimisation (PSO). Reduced simulation mean squared error by 10x, enabling control calibrations that suppressed measured hardware errors by 62%.

Code PDF
Swarm Robotics Reinforcement Learning arXiv:2211.03063

Developing Decentralised Resilience to Malicious Influence

Investigated collective perception in multi-agent swarms subject to Byzantine faults and adversarial attacks. Used reinforcement learning to dynamically weight peer communications, maintaining robust consensus across the swarm.

arXiv Code PDF
Adversarial ML Computer Vision arXiv:2202.08892

Adversarial Patches to Camouflage Military Assets

Developed an optimisation pipeline generating adversarial patches that prevent convolutional object detectors from identifying military assets. Formulated joint loss functions to maximise detection error while keeping patch colours perceptually bounded.
